# core — Minecraft progression core

Minecraft **1.21.1**, **Java 21**, Fabric и NeoForge. Версия **1.2.0**, ID `faustcore`.
Шесть навыков от действий, деревья способностей, покупка пределов за vanilla-уровни
опыта, выносливость и усталость. Пути, боевые и Create-интеграции пока не реализованы.


Последние уточнения: ускорение ограничено 200% (maximumGrowth≤2). Текст панели,
подсказок и HUD рисуется без тени. Броневой расход armorCost теперь 0.5: полный
незерит при Defense=0 (W=14, H=2) расходует 6 ед./с, то есть базовые 20 примерно
за 3.3 с непрерывного бега. При достижении нуля сохраняется exhausted: спринт
запрещён до полного восстановления **доступного** M, включая бег без брони.
Частичное восстановление блокировку не снимает; чёрная часть F не требует
полного сна для разблокировки. Состояние сохраняется при reconnect/respawn;
ресурс при истощении не продолжает списываться и не задерживает восстановление.
Настройка stamina.exhaustionLock (1 по умолчанию) позволяет отключить блокировку.
Старый стандартный armorCost=0.1 автоматически повышается до 0.5; явно отличающиеся
пользовательские ставки сохраняются. Перед этой миграцией stamina/progression
копируются в migration-v1.1-resource. Для работающего клиента/сервера нужен перезапуск
с новым JAR: перекомпиляция проекта не обновляет уже загруженные классы.


## Постоянные бонусы, иконки и настройки из меню модов

Constitution даёт +1 максимальный HP за уровень (на уровне 20 — 40 HP при vanilla
базе 20). Дополнительно сохраняется +0.2 выносливости за уровень. Повышение
максимума не является бесплатным лечением; при возрождении максимум применяется
до восстановления здоровья, при загрузке сохраняется записанное здоровье.
Intelligence даёт +0.01 к vanilla Luck за уровень, максимум +0.2. Это единицы
атрибута Luck, не универсальный шанс дополнительной добычи 20%.
Building даёт +1% скорости разрушения за уровень и +1 блок к дальности
взаимодействия с блоками и сущностями каждые 10 уровней. Бонусы деревьев добавляются
отдельно. Strength и Dexterity сохраняют свои бонусы урона и скорости бега,
Defense — переносимости брони и щитовых способностей.

Все ставки редактируются в skills.json: healthPerLevel, luckPerLevel, luckMaximum,
reachEveryLevels, reachPerStep, breakingPerLevel, breakingMaximum.
Визуальные ступени иконок — 0, 5, 10, 20 (iconTier1/2/3); используются исходные
locked_0/8/16/24.png. Всего перенесены 26 PNG (24 иконки + панель и вкладки),
побайтово без изменений. Лицензия и NOTICE включены в JAR.

**Меню модов → core → Настройки** открывает редактор всех разделов конфигурации:
числа, действия, интеграции, HUD и массивы деревьев. Это редактор JSON с выбором
разделов и прокруткой, а не набор слайдеров. Черновики сохраняются при переключении
разделов и изменении размера окна. Кнопка «Сохранить» проверяет всю связанную
конфигурацию и записывает один раздел через временный файл и атомарную замену.
Ошибочный JSON/диапазон/цикл дерева ничего не заменяет. Максимальная длина раздела
в сетевом редакторе — 8192 символа; большие конфиги можно редактировать файлами.

NeoForge использует встроенную кнопку настроек списка модов. Fabric требует
**Mod Menu 11.0.3** для 1.21.1 (не обязателен для самого core; в dev runtime
подключается автоматически). Официальный API:
https://github.com/TerraformersMC/ModMenu/blob/v11.0.3/src/main/java/com/terraformersmc/modmenu/api/ModMenuApi.java
В существующую сборку Fabric Mod Menu устанавливается отдельно.

В главном меню редактируются локальные файлы экземпляра. В мире редактируются
серверные настройки: сохранять может оператор permission level 2 или владелец
одиночного мира. Прочие игроки могут просматривать настройки, но сервер отвергает
изменения. Проверка полномочий выполняется сервером для каждого запроса, независимо
от состояния кнопки клиента. Payload config_edit передаёт только фиксированное имя
раздела и JSON, config_result — разрешение и результат. Произвольные пути запрещены.
Клавишу открытия по-прежнему меняют в стандартном управлении Minecraft.


## Изменения 1.2 — актуальные правила (2026-11-08)

Этот раздел заменяет прежние ставки бонусов. Strength даёт +1% урона/L,
Dexterity — +1% скорости атаки/L и +1% скорости **только спринта**/L.
Constitution — +1 HP и +1 выносливости/L. Intelligence — +0.01 Luck/L до +0.2.
Building — +1% ломания/L, +1 дальности/10L, максимум дополнительной дальности +3.
Defense — +1 брони/2L, помимо прежней переносимости и способностей щита.

Все бонусы атрибутов задаёт **statBonuses.json** (доступен и из меню модов).
Пример одной дополнительной записи в массиве — Dexterity даёт +1 HP/L:

```json
{"id":"dexterity_health","skill":"dexterity","attribute":"minecraft:generic.max_health","perLevel":1}
```

Необязательные поля: operation (`add`, `multiply_base`, `multiply_total`),
everyLevels (по умолчанию 1), maximum (индивидуальный потолок бонуса), sprintOnly.
Для +1% применяется perLevel=0.01 и operation=multiply_base; для дальности —
everyLevels=10, perLevel=1, maximum=3. Встроенные строки можно изменять, удалять,
добавлять. ID должны быть уникальны. Атрибут должен существовать и быть доступен
игроку; неизвестные атрибуты не применяются. Удалённые правила снимают модификатор
при пересчёте. Неиспользуемые старые числовые stat-поля skills.json считаются legacy;
для этих атрибутов используйте именно statBonuses.json. Скорость ломания остаётся
в skills.json, выносливость — stamina.json, условия и эффекты узлов — abilities.json.

Эффекты открываемых способностей дерева усилены ×10; щитовые скидки ограничены
95% согласно существующему ограничению. Second Wind заменён специальным эффектом:
пассивное восстановление **всегда** равно stamina.runCost (0.2 ед./с), в том числе
при расходе. Поэтому бег без брони/лишней нагрузки не истощает запас с этой
способностью; броня, удары и плавание остаются дополнительными расходами.
Базовый опыт действий удвоен через progression.trainingMultiplier=2; счётчики
условий способностей не удваиваются. Отображаемый бонус предела по-прежнему ≤200%.
Выше предела slowdown=0.5 вместо 0.25: штрафная составляющая удвоена.

Каждый ближний удар, включая промах, стоит stamina.attackCost=1. При нехватке
запаса удар по сущности отклоняется сервером; одна атака не оплачивается повторно
пакетом анимации. Взмахи при добыче блоков не являются отдельной платой за удар.
Creative/Spectator и отключённая выносливость сохраняют прежнее исключение.

Шкала расположена над голодом; числа всегда округляются вниз до целых.
client.hudX/hudY — смещения от этого якоря. Усталость остаётся чёрной частью справа.
Обычный костёр снимает ровно 1 ед. каждые 25 с отдыха: скорость прежняя 0.04 ед./с,
остаток времени сохраняется между подходами. Сон восстанавливает постепенно.
Костёр душ добавляет 0.04 ед./с при нахождении рядом, независимо от неподвижности;
огонь душ — 0.1 ед./с, пока игрок горит после контакта с ним. Если одновременно
действуют несколько источников, их изменения суммируются. Все ставки настраиваемы
в fatigue.json. Текущая причина горения душ сохраняется, пока огонь не потушен.

Миграции сохраняют конфиги в migration-v1.2 и migration-v1.2-environment перед
изменением правил. Для применения нового кода замените JAR и перезапустите игру.
Подсказки панели теперь рисуются последними и выше карточек/вкладок; тень выключена.

## Сборка и запуск

```powershell
./gradlew.bat build
./gradlew.bat :fabric:runClient
./gradlew.bat :neoforge:runClient
```

Запускайте клиенты по очереди. Используется Wrapper, отдельный Gradle не нужен.
Первый запуск требует сети. Для имеющегося кэша проекта:

```powershell
$env:GRADLE_USER_HOME = Join-Path (Get-Location) '.gradle-user-home'
./gradlew.bat build --offline
```

Итоговые JAR:

- `fabric/build/libs/faustcore-fabric-1.21.1-1.2.0.jar`;
- `neoforge/build/libs/faustcore-neoforge-1.21.1-1.2.0.jar`.

В обычной сборке положите один соответствующий JAR в `mods` Minecraft 1.21.1.
Не используйте `sources`, `javadoc`, `dev` или старые JAR `examplemod`/core 1.0.0.
Fabric требует Loader ≥0.16.9 и Fabric API для 1.21.1, NeoForge — ≥21.1.80 из ветки
21.1.x. Сервер и все клиенты должны использовать одинаковую версию core своего
загрузчика. Architectury и GeckoLib не требуются. Версии зависимостей не менялись.

## Панель и выносливость

Панель открывается вкладкой с книгой над инвентарём или клавишей **K**.
Привязка меняется в **Настройки → Управление → Назначение клавиш → core**.
Обзор имеет две колонки, иконки и короткие описания шести навыков. Нажмите навык,
чтобы увидеть описание, практику, скорость роста, цену предела и дерево способностей.
Наведите на способность, чтобы увидеть эффект и предшественника. Стрелки листают
дерево. Обратная вкладка возвращает в инвентарь. Отдельных титулов и восьми навыков
из источника нет.

Базовая выносливость — **20 единиц**, быстро восстанавливается после паузы.
Конституция и способности могут увеличить базовый запас; коэффициенты настраиваются.
Усталость измеряется в таких же единицах и показана **только чёрным участком справа
в общей полоске**. Отдельной подписи/процентов усталости нет. Расход: бег в броне
сверх допустимой нагрузки и плавание против течения. Сон и неподвижный отдых у
зажжённого костра постепенно освобождают чёрную часть. Смерть её не обнуляет.

Мягкий предел начинается с 10, покупается по **+1**, не выше **20**.
Сами навыки могут расти выше предела с замедлением. Ниже предела скорость равна
`min(2, предел / max(1, уровень навыка))`: 10/5 — 200%, 12/4 — также 200%.
Цена покупки — `ceil(n + m/5)` vanilla-уровней, где n — выбранный текущий предел,
m — сумма всех пределов. В начале цена 22 уровня. Strength → Building → Strength
стоят 22, 23, 24 уровня; меняется только выбранный предел. Дробная часть vanilla
полоски сохраняется при оплате. Опыт кошелька отображается в уровнях, практика —
отдельным процентом текущего уровня навыка.

## Команды

Обычному игроку доступны помощь, свой статус и покупки:

```text
/core help
/core status
/core cap strength
/core cap buy strength
/core unlock faustcore:controlled_strike
/core path example:path
```

Пути должны быть зарегистрированы внешним модом. Неизвестные ID и невыполненные
условия не выдают награду. Используйте Tab для имён навыков и способностей.

Команды администратора/консоли (permission level 2) поддерживают имена и селекторы:

```text
/core status @a
/core skill set @s strength 10
/core skill add @s constitution 2
/core skill xp @s building 50
/core cap set @s strength 20
/core ability grant @s faustcore:shield_care
/core ability revoke @s faustcore:shield_care
/core stamina set @s 10
/core stamina fill @s
/core fatigue set @s 4
/core fatigue clear @s
/core reset @s
/core reload
```

`skill xp` добавляет единицы практики с текущим множителем, а не vanilla XP.
`skill set/add` изменяют уровень и сбрасывают практику внутри него; они не открывают
способности автоматически. `cap set` меняет только предел (0…20), без оплаты;
`ability grant` обходит игровые условия, `revoke` отзывает также потомков узла.
`stamina fill` заполняет только доступную часть, не снимая усталость.
`reset` удаляет **весь** прогресс выбранного игрока, включая путь и усталость.
Для консоли указывайте имя игрока или @a, поскольку @s без игрока не подходит.

## Проверка изменений

Создайте отдельный тестовый мир Survival, включите команды. Creative/Spectator
не получают опыт действий. Проверьте на обоих загрузчиках:

1. Вкладка над инвентарём, возврат в инвентарь, переназначение K в управлении;
   обе локализации, описания навыков и подсказки способностей.
2. `/core skill set @s strength 5` → скорость 200% при пределе 10. Предел 15
   при уровне 5 → также 200%. `/core cap set @s strength 20` → покупка выше 20 запрещена.
3. `/experience set @s 50 levels`, затем покупка предела в другой ветке:
   списываются уровни согласно цене; другие пределы неизменны.
4. `/core fatigue set @s 4` и `/core stamina fill @s`: справа чёрная часть,
   доступно 16 из базовых 20 (при нулевой Constitution). Нет отдельной подписи F.
5. Урон, щит, бег, установка блоков, крафт, книги, торговля, зачарование и структуры
   развивают соответствующие навыки. Получение урона от окружения тоже допустимо.
6. Сон/костёр, смерть/возрождение, переподключение, перезапуск и измерение:
   прогресс/усталость сохраняются без повторных бонусов.
7. Обычный игрок без OP не может выполнять set/add/grant/reset/reload; покупки
   и обычное открытие способностей доступны. Проверьте также консоль и @a.

Автоматические тесты включены в build (`:common:modelTest`): формулы, миграция,
предел 20, деревья, ресурсы, настоящий парсер Brigadier и права команд.
Они не заменяют полную визуальную и игровую проверку персонажа.

## Конфиги и обновление с 1.0

Папка: `<экземпляр Minecraft>/config/faustcore/`. Dev Fabric:
`fabric/runs/client/config/faustcore/`; dev NeoForge: `neoforge/run/config/faustcore/`.
Все параметры баланса находятся в JSON: progression, skills, actions, abilities,
stamina, fatigue, armor, integrations, client. `/core reload` перечитывает их;
некорректный reload сохраняет предыдущую рабочую конфигурацию.

При обнаружении старого progression.json автоматически создаётся резервная копия
изменяемых конфигов в `migration-v1/`, затем обновляются формулы, масштаб ресурса
и единицы усталости. Старые сохранения schema=1 преобразуются в schema=2 при загрузке;
достигнутые пределы сохраняются до нового максимума 20. Перед обновлением рабочего
мира сделайте обычную резервную копию мира. Старый `client.openKey` заменён штатной
привязкой в options.txt; назначение клавиши больше не приходит от сервера.

`stamina.enabled: 0` отключает ресурс, `fatigue.enabled: 0` — только влияние и
изменение усталости (история сохраняется), `client.hud: 0` — только HUD.
Все остальные игровые параметры, включая HUD в текущей версии, задаёт сервер.

Dedicated server: `./gradlew.bat :fabric:runServer` или `:neoforge:runServer`.
EULA принимает владелец, остановка — `stop`. NeoForge dev-клиент и dev-сервер пока
используют общий `neoforge/run`: не запускайте их одновременно.

## Проверка 1.2 и пример проверки в игре

Общий дополнительный reach именно от Building ограничивает skills.buildingReachMaximum
(по умолчанию 3), даже если в statBonuses.json добавлено несколько правил дальности.
Индивидуальный maximum записи остаётся дополнительным ограничением.

Для теста: /core skill set @s dexterity 10 — +10% скорости атаки и спринта,
ходьба без бонуса; /core skill set @s defense 6 — +3 брони;
/core skill set @s building 100 — reach от Building остаётся +3.
Откройте способности и наведите курсор на первую/вторую строку и вкладки:
подсказки должны отображаться поверх карточек. Над голодом отображаются только
целые числа с округлением вниз. Проверяйте обычный костёр 25 секунд, затем
костёр душ и горение от огня душ. Second Wind должен компенсировать базовый бег,
но не броневую нагрузку и не удары. Новые Java-классы требуют перезапуска с JAR1.2.
Игровые сценарии этого релиза вручную полностью не проверены.
