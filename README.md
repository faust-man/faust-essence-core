# core — Minecraft progression core

Minecraft Java **1.21.1**, **Java 21**, Fabric и NeoForge. Mod ID: `faustcore`.
Шесть навыков от действий, деревья способностей, мягкие пределы за vanilla XP,
выносливость и усталость. Будущие пути, боевые и Create-интеграции пока не реализованы.

## Сборка и запуск

Используйте JDK 21 и Wrapper из корня:

```powershell
./gradlew.bat build
./gradlew.bat :fabric:runClient
./gradlew.bat :neoforge:runClient
```

Клиенты запускайте по очереди. `build` включает `:common:modelTest` — проверки
формул, покупок, деревьев, сохранения и выносливости. Отдельный Gradle не нужен.
При недоступности обычного каталога Gradle используйте локальный кэш проекта:

```powershell
$env:GRADLE_USER_HOME = Join-Path (Get-Location) '.gradle-user-home'
./gradlew.bat build
```

Первый запуск требует сети для зависимостей и assets. `--offline` работает после
их загрузки. Версии загрузчиков, mappings и плагинов не обновлялись.

## Установка JAR

В обычном экземпляре Minecraft 1.21.1 скопируйте один JAR в `mods`:

- Fabric: `fabric/build/libs/faustcore-fabric-1.21.1-1.0.0.jar`;
- NeoForge: `neoforge/build/libs/faustcore-neoforge-1.21.1-1.0.0.jar`.

Не берите `sources`, `javadoc`, `dev` и не устанавливайте обе версии одновременно.
Fabric требует Loader ≥0.16.9 и Fabric API для 1.21.1. NeoForge — ≥21.1.80 из ветки
21.1.x. На сервер и все клиенты ставьте одинаковую версию core своего загрузчика.
Architectury и GeckoLib не требуются.

## Проверка в игре

Создайте отдельный мир **Survival**. Creative/Spectator не дают опыт. Клавиша **K**
открывает навыки; на HUD показаны выносливость и усталость. Есть английская и русская
локализации. Полный план проверки и API — в
[docs/DEVELOPER_CONTEXT.md](docs/DEVELOPER_CONTEXT.md).

1. Бег без брони развивает Dexterity; бег в броне — также Defense. Сверх допустимой
   нагрузки тратится Stamina, растёт Fatigue. Ходьба и стояние ресурс не расходуют.
2. Реальный урон любого происхождения развивает Constitution; заряженные прямые
   удары по враждебным мобам — Strength. Блокирование щитом развивает Defense.
3. Написанные книги, зачарование, структуры Minecraft и торговля развивают
   Intelligence; установка блоков и крафт — Building.
4. Добавьте XP командой `/experience add @s 1000 points`, если разрешены команды.
   Купите предел Strength, затем Building: цены общие — 100, 150, 225, 338, 507 XP;
   повышается только выбранная ветка. Выше мягкого предела рост продолжается.
5. Попытайтесь открыть способность до/после выполнения уровня, действия и
   предшественника. Повторное открытие не должно давать второй бонус.
   Кнопки `<` и `>` переключают страницы дерева.
6. В режиме плавания двигайтесь против течения: ресурс расходуется; по течению
   и в стоячей воде — нет. Постойте у зажжённого костра или поспите: Fatigue
   снимается постепенно. Быстрый пропуск ночи не равен полноценному отдыху.
7. Проверьте смерть, возрождение, выход/вход, перезапуск и смену измерения:
   прогресс сохраняется, усталость не сбрасывается, бонусы не дублируются.

Повторите на обоих загрузчиках. Для ускорения теста временно уменьшите цену уровней
и условия дерева в конфиге тестового экземпляра; затем `/core reload` и переоткройте
экран. Игровая проверка персонажа в текущей среде вручную не выполнена; сборка,
модельные тесты и журналы старта клиентов не заменяют её.

## Конфиги и команды

Папка: `<экземпляр Minecraft>/config/faustcore/`, создаётся при запуске.
Dev Fabric: `fabric/runs/client/config/faustcore/`; NeoForge: `neoforge/run/config/faustcore/`.
Файлы JSON: progression, skills, actions, abilities, stamina, fatigue, armor,
integrations, client. Единицы и ограничения описаны в DEVELOPER_CONTEXT.md.

- `/core` — помощь и синхронизация;
- `/core cap strength` — повышение предела;
- `/core unlock faustcore:controlled_strike` — открытие способности;
- `/core path namespace:path` — выбор зарегистрированного внешнего пути;
- `/core reload` — перезагрузка конфигов, нужны права оператора уровня 2.

В stamina.json `enabled: 0` отключает ресурс и ограничения ядра. В fatigue.json
`enabled: 0` отключает только влияние/накопление усталости, сохраняя историю.
В client.json `hud: 0` скрывает HUD; `openKey: 75` — клавиша K (код GLFW).
Переключатели числовые: 0/1. В multiplayer параметры, включая текущий HUD, задаёт
сервер; локальное переопределение HUD пока не реализовано.

## Dedicated server

```powershell
./gradlew.bat :fabric:runServer
./gradlew.bat :neoforge:runServer
```

Не запускайте оба на одном порту одновременно. Остановка — команда `stop`.
EULA принимает владелец сервера. NeoForge dev-клиент/сервер используют общий
`neoforge/run`: запускайте по очереди либо проверяйте сеть в отдельных экземплярах.

## Структура и происхождение

- common — модель, конфиги, API, ванильные Mixin и клиентский интерфейс;
- fabric / neoforge — точки входа, сеть и платформенные сервисы;
- buildSrc — общие Gradle-конвенции; work_notes — игнорируемые рабочие заметки.
